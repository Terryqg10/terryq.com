# StatusBadge

Indica el estado de un proyecto: punto + palabra en mono.

**Variantes:** por defecto (punto relleno `live`) para "Online" / "En producción"; `tq-status--demo` (punto hueco) para demos.

**El consumidor aporta:** la palabra del estado. El punto es decorativo (`aria-hidden`); la palabra transmite el estado.

**Reglas:** nunca solo el punto. Se usa en filas de proyecto, ficha del caso y fila de prueba del hero.
